## 🚀 КАК ИСПОЛЬЗОВАТЬ

### ✅ Вариант 1: Выбрать модель прямо из списка

```
1. Производитель уже выбран (Энергомера)
2. Видите список из 6 моделей ниже
3. Нажимаете на нужную модель (например "CE308")
   ↓
4. Модель АВТОМАТИЧЕСКИ переключилась ✓
5. Приложение загрузило конфигурацию этой модели
```

### ✅ Вариант 2: Найти модель через поиск

```
1. Производитель уже выбран (Энергомера)
2. Видите полный список модели (6 штук)
3. Пишете в поле "Напишите для поиска..." → "308"
   ↓
4. Список фильтруется в реальном времени:
   - Видна ТОЛЬКО "Энергомера CE308 (0x15)"
   - Остальные модели скрыты
   ↓
5. Нажимаете на CE308
   ↓
6. Модель переключилась ✓
```

### ✅ Вариант 3: Смена производителя

```
1. Были на "Энергомера" с CE308
2. Нажимаете на селект "Производитель" и меняете на "Меркурий"
3. Происходит:
   - Поле поиска автоматически очищается
   - Список обновляется с моделями Меркурия
   - Первая модель Меркурия загружается
   - Фокус переходит на поле поиска (для удобства)
   ↓
4. Видите новый список моделей Меркурия
```

## 🔍 ПОИСК РАБОТАЕТ ПО

- **Названию модели**: `207`, `308` → найдет CE207, CE308
- **Производителю**: `mercury`, `neva` → найдет модели производителя  
- **Журналу**: `0x1E`, `1E`, `0x15` → найдет модели с этим журналом

### Примеры поисков:

| Вводите | Результат |
|---------|-----------|
| `207` | Энергомера CE207 |
| `308` | Энергомера CE308 |
| `0x1E` | Все модели с журналом 0x1E |
| `150` | Меркурий 150 |
| `414` | Нева 414 |
| `CE` | Все Энергомеры (содержат "CE") |

## ⚡ ОСОБЕННОСТИ

✅ **Автоматический выбор** - первая видимая модель в поиске выбирается автоматически  
✅ **Реальное время** - фильтрация происходит при каждом нажатии клавиши  
✅ **Плавное открытие списка** - при фокусе на поиске список расширяется  
✅ **Сохранение** - выбранная модель сохраняется в браузер  
✅ **Восстановление** - при открытии приложения загружается последняя модель

## 💾 АВТОСОХРАНЕНИЕ

**Приложение запоминает:**
- ✓ Последний выбранный производитель
- ✓ Последнюю выбранную модель

**Восстановление:**
- При открытии страницы → загружается последний выбор
- Все параметры (период, задача, объекты) тоже восстанавливаются

## 🎨 ВИЗУАЛЬНЫЕ ПОДСКАЗКИ

- **Поле поиска в фокусе** → синяя рамка и тень (привлекает внимание к списку)
- **Список при фокусе** → также подсвечивается для единства
- **Видимые опции** → отображаются нормально
- **Скрытые опции** → не видны в списке

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### Q: Что если я ввожу что-то несуществующее?
**A:** Список не будет показывать результатов. Просто清清 поле и список вернется к исходному.

### Q: Могу ли я выбрать из списка без поиска?
**A:** Конечно! Просто нажмите на нужную модель в списке. Поиск использовать не обязательно.

### Q: Поле поиска очищается при смене производителя? 
**A:** Да, автоматически очищается для удобства.

### Q: Как вернуть все модели если я в поиске?
**A:** Удалите текст в поле поиска (очистите его) → список вернется к полному.

## 📋 АЛГОРИТМ РАБОТЫ

```
1. ПРИ ЗАГРУЗКЕ СТРАНИЦЫ:
   └─ Восстановить из localStorage
   └─ Заполнить список моделей
   └─ Загрузить конфигурацию модели

2. ВЫБОР ПРОИЗВОДИТЕЛЯ:
   └─ Обновить список моделей для этого производителя
   └─ Очистить поле поиска
   └─ Загрузить первую модель производителя

3. ВВВОД ТЕКСТА В ПОИСК:
   └─ Для каждого символа:
   │  ├─ Проверить все модели
   │  ├─ Если совпадает → показать (display: '')
   │  └─ Если не совпадает → скрыть (display: 'none')
   └─ Первую видимую модель → выбрать

4. КЛИК НА МОДЕЛЬ:
   └─ Переключиться на эту модель
   └─ Сохранить в localStorage
   └─ Загрузить конфигурацию
   └─ Обновить интерфейс
```
